# Lima cerita bahan — siap tempel ke Studio → Jurnal

Teksnya **punyamu**, diambil dari caption Instagram yang sudah kamu tulis dan sudah kamu cek
faktanya. Yang saya buang cuma bagian yang hanya masuk akal di Instagram:

- hashtag
- "Harganya lebih murah di website. solivagantscent.com" — pembaca jurnal **sudah** di website
- bagian "Story pendamping", "Prompt foto AI", "Catatan cek", "Sumber gambar"

Yang saya **tidak** ubah: urutan kalimat, pilihan kata, fakta. Tidak ada satu kalimat baru.

**Cara pakai:** Studio → Jurnal → tombol tulis baru, lalu isi per kolom di bawah.
Status biarkan **Draft** sampai kamu puas — draft tidak terlihat pembeli.
Kolom slug tidak ada di form; alamatnya dibuat otomatis dari judul.
"Produk terkait" itu dropdown berisi nama produk — bukan kolom ketikan.

**Judul**: saya pakai kalimat pembukamu sendiri apa adanya, supaya tidak ada kata karangan saya
di judul. Ganti sesukamu — itu memang bagian yang paling pantas kamu tulis sendiri.

**Gambar**: kolom cover sengaja saya kosongkan. Caption-mu mencantumkan kredit foto Wikimedia
(beberapa lisensi CC BY **mewajibkan** kredit). Kalau kamu pasang salah satu foto itu sebagai
cover, tempel kreditnya di baris terakhir isi artikel — daftarnya masih ada di file caption
masing-masing. Kalau cover-nya foto sendiri, tidak perlu kredit.

**Tapi ada konsekuensinya kalau cover dibiarkan kosong:** artikel tanpa cover otomatis memakai
foto brand `perfumer-at-work.jpg` sebagai gambar preview. Artinya kalau kelima artikel ini
terbit tanpa cover, kelimanya akan tampil dengan **gambar preview yang sama persis** di
WhatsApp dan Instagram — lima tautan berbeda, satu foto. Masih jauh lebih baik daripada preview
tanpa gambar sama sekali, tapi kalau kamu mau kelimanya kelihatan beda, isi cover-nya.
Foto Wikimedia di file caption masing-masing sudah cukup untuk itu.

## Kenapa ini penting sekarang

Caption Gaharu-mu bilang: *"Ceritanya ada di solivagantscent.com."* Sampai hari ini halaman itu
tidak ada — jurnal di website hanya punya **satu** artikel terbit, dan isinya bukan soal bahan.
Jadi siapa pun yang menuruti caption itu sampai di website dan tidak menemukan apa pun.

Lima artikel ini menutup lubang itu, dan sejak PR #517 tautannya jalan dua arah: begitu artikel
terbit dengan "Produk terkait" terisi, halaman parfumnya ikut menampilkan tautan ke ceritanya
tanpa kamu kerjakan apa-apa lagi.

## Satu hal teknis yang perlu kamu tahu

Peta situs (sitemap) dan halaman HTML siap-bagikan untuk tiap artikel dibuat **saat deploy**,
bukan saat kamu menekan Terbitkan. Jadi urutannya:

1. kamu terbitkan artikel di Studio → langsung bisa dibaca di website
2. tapi Google dan preview link WhatsApp/Instagram belum melihatnya
3. baru setelah deploy berikutnya, artikel masuk sitemap dan dapat halaman HTML sendiri

Artinya setelah lima artikel ini terbit, minta saya deploy sekali (atau tunggu PR berikutnya
masuk). Setelah itu website punya **enam** artikel terindeks, bukan satu.
