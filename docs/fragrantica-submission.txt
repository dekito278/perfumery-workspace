NOTE ON THE NOTE NAMES
  The website labels reconstructions as accords — "Animalic Accord", "Oud Accord",
  "Deer Musk Accord" — because an accord is what they are, and because a bottle
  crossing a border should not read as an animal product. Fragrantica keeps its own
  fixed vocabulary, so the names below are those labels mapped to it. The website is
  not being changed to match: an editor normalises to the Fragrantica list anyway, so
  changing it would lose the customs clarity and gain nothing.

  Ambrocenide is mapped to Amberwood and NOT to Ambergris. It is a Symrise molecule
  made from cedarwood terpenes; ambergris comes from the sperm whale, CITES Appendix I.

  Maskumambang's "Deer Musk Accord" is listed here as Musk, by the same reasoning: real
  deer musk is CITES Appendix I, the bottle contains an accord and not the animal, and a
  permanent public listing should not say otherwise. The website keeps its own label.

  The four drifted notes were given the nearest real note:

    Lintang Asmoro  top    + Clean notes   exact match for the shop's "Clean Accord" (1807)
    La Rose         top    Honey -> Nectar both exist; the shop says Nectar (1694)
    HUG N°1         top    + Iodine        a JUDGEMENT. The shop says "Medicinal", which
                                           Fragrantica has only inside "Chinese Medicinal
                                           Herbs". Iodine (1372) is its medicinal-metallic
                                           note and sits beside the Metallic Notes already
                                           there. Camphor and Eucalyptus read too cold and
                                           too herbal.
    Pantura         heart  + Wormwood      a JUDGEMENT, and the least certain line here.
                                           The shop says "Bitter"; Fragrantica has no bare
                                           "Bitter". Wormwood (369) is its bitter-herb note.
                                           Bitter Orange was rejected: the top already
                                           carries Orange, Lime and Bergamot.

  Those two judgements, and Jata Bhumi's Aquatic -> Sea Water, are the only places in this
  file where a word was chosen rather than read off the shop or the index. Change them if
  they are wrong — everything else is verified.
