NOTE ON THE NOTE NAMES
  The website labels reconstructions as accords — "Animalic Accord", "Oud Accord",
  "Deer Musk Accord" — because an accord is what they are, and because a bottle
  crossing a border should not read as an animal product. Fragrantica keeps its own
  fixed vocabulary, so the names below are those labels mapped to it. The website is
  not being changed to match: an editor normalises to the Fragrantica list anyway, so
  changing it would lose the customs clarity and gain nothing.

  Ambrocenide is mapped to Amberwood and NOT to Ambergris. It is a Symrise molecule
  made from cedarwood terpenes; ambergris comes from the sperm whale, CITES Appendix I.

BEFORE SENDING — one thing left
  Wongka! has no top note. Its only one was "Fresh", which is not a Fragrantica
  note and which this file will not invent a replacement for. Dekito's own
  description of it — a waterfall that seems to be breathing, wet leaves that feel
  alive — points at water rather than citrus, and the shop already uses Aquatic and
  Ozonic on Jata Bhumi. Pick one and put it on the Top line:

      Water Notes      closest to "a waterfall that seems to be breathing"
      Aquatic Notes    the same family, already used elsewhere in this shop
      Ozonic Notes     cooler and airier, also already used here
      (or leave it out — three notes is thin but a missing one is not wrong)

  Wongka! carries only three notes in total. That is fine to submit; it is just
  less than the others, in case more belong there.
